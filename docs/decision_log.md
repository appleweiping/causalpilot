# CausalPilot decision log

This file is the shared project memory for product, research, engineering, and review decisions.

## 2026-07-19 — Research thesis

- **Decision:** Build CausalPilot around **TRACE** (Trajectory Risk and Action Control for Experimentation). Risk indices are not called calibrated probabilities without held-out reliability evidence.
- **Falsifiable hypothesis:** under a fixed experiment and human-attention budget, a trajectory-aware risk gate may reduce harmful deployments at matched coverage or improve value at matched risk. The current artifact does not establish that comparison.
- **Reason:** the contribution must be a measurable decision mechanism, not an agent wrapper or a visual-only multi-agent demo.
- **Constraint:** no result is presented as evidence until generated by a checked-in, reproducible evaluation command.

## 2026-07-19 — Product scope

- **Decision:** The flagship mission is a fashion recommendation intervention with a conversion objective, a diversity guardrail, and a 30,000-impression experiment budget.
- **Agent actions:** diagnose, run a randomized probe, ask one structured human question, deploy one segment or all passing segments, pause, roll back, or abstain.
- **Risk state:** model, causal, data, and environment risk are calculated separately and exposed with an append-only in-memory transition trace.
- **Demo semantics:** 3D geometry must encode data: cluster size is sample size, color is risk/uplift, particles are traffic, and edges are causal or decision dependencies.

## 2026-07-19 — Engineering scope

- **Decision:** FastAPI provides deterministic statistical tools and an explicit state machine. Next.js + React Three Fiber provides the control room.
- **Offline-first demo:** the UI must complete the full narrative from a seeded local simulator when the API is unavailable. API-key-dependent LLM orchestration is an optional adapter, never a run-time requirement.
- **Evaluation:** a lightweight seeded benchmark ships in the repository; adapters document how to run against Open Bandit Dataset and Criteo Uplift without committing those datasets.
- **Reproducibility:** every displayed benchmark number must trace to a versioned JSON artifact containing configuration, seeds, and metric definitions.

## 2026-07-19 — Delivery scope

- Public GitHub repository with bilingual landing documentation.
- One-command local run, Docker configuration, tests, lint/type checks, and CI.
- Research landscape, product specification, 4–6 page technical report and limitations/failure cases.
- A static live demo may use the deterministic client simulator; the full backend remains available for local research runs.
